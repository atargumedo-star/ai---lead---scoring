AI Lead Scoring for Startups

Proyecto de Machine Learning desarrollado con Python para ayudar startups a identificar usuarios con mayor probabilidad de convertirse en clientes.

Problema

Muchas startups pierden tiempo contactando usuarios sin intención real de compra.

Este proyecto utiliza Machine Learning para analizar comportamiento de usuarios y generar un score predictivo para priorizar leads.

Caso práctico

Un equipo de growth o ventas puede usar este sistema para:

- priorizar usuarios con más potencial,
- automatizar decisiones comerciales,
- reducir tiempo perdido,
- mejorar conversiones.

Tecnologías

- Python
- Pandas
- Scikit-learn
- Machine Learning

Objetivo

Automatizar análisis de leads y acelerar decisiones usando IA.
